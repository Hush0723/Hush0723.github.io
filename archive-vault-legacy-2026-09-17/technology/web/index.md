# Web 开发

Web 是一套文档、网络协议与可编程运行环境共同构成的平台。

## 三层模型

- HTML 描述内容结构
- CSS 表达视觉与布局
- JavaScript 管理行为和状态

优秀的 Web 产品同时依赖工程能力与[[root/art/interaction-design|交互设计]]。
